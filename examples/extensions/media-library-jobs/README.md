# Local media library jobs

This is a general trusted Node extension, with no specialized executable type.
Build it using the local SDK CLI, then install its compiled dist folder or use
Settings → Plugins → Create & develop → Start session with the built project.
Installing or inspecting it does not execute code. Activate it only after the
native Node access warning. The example version is unchanged.

The historical bytes live under tests/fixtures/plugins/legacy for compatibility
verification only. Their executable runtime is retired; this source is the Node replacement.
