## PRESERVE (audit only — define the language, change nothing)

### 1. Home Screen — `HomeScreen.jsx` — PRESERVE
The reference surface. Language extracted for the design system: stage hero (292px side +
true-ratio photo frames on a floor line), eyebrow micro-labels (11px/700/+1.4px uppercase,
#c4b5fd), 35px/800 hero headline, pill segmented control (`.seg`, 99px, primary fill when
on), quick-action rows with 34px icon chips, gallery cards (surface-1, 12px radius,
translateY(−1px) hover, primary border), pill search (99px, 230×32px), footer strip.
Everything else in the app must harmonize with this, not the reverse.

### 2. Sidebar / icon dock — `LeftPanel.jsx` dock + `.dock*` CSS — PRESERVE
70px column, gradient-tinted wrap (violet wash fading at 42%), 12px-radius buttons with
10px labels, active = full brand gradient (135deg #825cfb→#6d28e0) with violet glow shadow,
scroll arrows with gradient masks. This is the shell's signature; panels to its right must
not compete with it.

## REDESIGN-STRUCTURAL (top 10 — layout pattern is the problem)

### 15. Media library panel — `LeftPanel.jsx` `MediaTab`/`MediaCard` + `SideNav.jsx`
**Hamza-flagged (screenshot).** The panel is a near-verbatim CapCut library clone: a
second full-height category rail (Import / Record screen / accordion groups Yours /
Stock videos / Stock photos) nested inside the panel, plain pill rows (`.side-btn`,
32px, surface-3 blocks stacked with no rhythm), and a uniform 16:9 asset grid whose
cards are bare thumbnails + filename. Two nested navigation columns (dock + rail) eat
~40% of the editor's width before any media appears. The dropzone empty state is the
only designed moment.
*Direction:* collapse sources into one ClipCraft source switcher (segmented header:
Yours / Favorites / Stock with Import + Record as actions, not nav rows); media wall
with ratio-true masonry and hover action bar; keep every existing capability.

### 16. Audio library (Music / Sound FX / Trolls / TTS / Credits) — `AudioLibrary.jsx`
**Hamza-flagged (screenshot).** Same CapCut rail pattern as Media (Music > Vlog, Happy,
Chill, Epic… as flat text rows), then long undifferentiated `.lib-row` lists (play dot +
two text lines + plus) under a plain `.tab-title`. The licensing note is a loose
paragraph, loading is a bare spinner line, and five different sub-surfaces (music list,
SFX groups, troll list, TTS form, credits card, recorder card) share no visual system.
*Direction:* one audio surface with a designed category header (chips, not a rail),
track rows with waveform-tinted leading art and license pills as first-class elements,
and the recorder/TTS as designed cards in the same language as Home's quick actions.

### 17. Stock libraries — `StockLibrary.jsx`
Generic search + chip cloud + uniform grid; thumbnails show a centered spinner box
(`.stock-ph`) with no skeleton; the no-API-key state is a plain `.card`. Reads as a
web embed, not a desktop tool surface.
*Direction:* same media-wall language as #15 (shared asset grid), skeleton tiles while
loading, key-required state as a designed onboarding card.

### 18. Clip inspector — `ClipInspector.jsx` (+ `AnimationPanel.jsx`)
The CapCut properties-panel pattern end-to-end: underline tab strip (Video / Animation /
Audio / Speed / Adjust), stacked `.ci-section` cards, `.numbox` rows, native checkboxes
and selects. It is the densest legacy layout in the app and the one users stare at.
*Direction:* rebuild on the ProjectDetails pattern (#7): visual controls first
(segmented groups, ratio-style tiles where apt), sections as deck-toned groups with
micro-labels, keyframe nav as a designed unit; preserve every control and tab.

### 19. Text panel + text-template browser — `LeftPanel.jsx` `TextTab`, `TextInspector.jsx` `TemplateGrid`
Template tiles render live text samples over a generic slate gradient
(`.text-sample`: linear-gradient #334155→#1e293b — not a brand surface), in a plain
grid with a star; the category navigation is the same legacy rail. The templates
themselves are being renewed (in-flight #12) but the browser chrome will still read
generic.
*Direction:* template gallery in the Home stage language (true-ratio stage cards,
sample text on brand surfaces with the template's own colors), categories as chips.

### 20. Text inspector — `TextInspector.jsx`
A long legacy form: `.seg-tabs` strip, then stacked `.field` rows and `.sub-head`
ruled sections (Stroke / Background / …) with chips and icon-toggles. Functional but
visually indistinguishable from the original app's form stack.
*Direction:* group into designed property cards (Type / Fill / Stroke / Background /
Animation) using the inspector language of #7/#18; keep FontPicker and TextAnimBrowser
behaviour, restyle their chrome to match.

### 21. Modal family base — `.modal` in `styles.css`; `ExportDialog.jsx`, `ConfirmDialog.jsx`, `CloseDialog.jsx`, `SequenceDialog.jsx`
Four dialogs share one generic pattern — 440px centered card, 52px circular icon badge,
17px title, centered text, row of buttons. It is the original app's dialog language
verbatim, and it clashes with the one redesigned dialog (About, #41) which proves the
app can do better (400px, 20px radius, hero layout). Export's progress/done/error
states deserve a designed export card (file summary, reveal action), not a spinner in
a generic box; Sequence's comparison table is plain HTML table styling.
*Direction:* one ClipCraft dialog spec (from About's tokens: 20px radius, deck
gradient, hero icon treatment); Export gets a purpose-built layout; Sequence gets a
two-column settings-diff visual instead of a table.

### 22. Timeline toolbar — `Timeline.jsx` `.tl-toolbar`
A flat strip of 30px ghost icon buttons separated by hairlines (`.tool-sep`), with the
zoom slider and time readout inline — the original editor toolbar pattern, visually
unrelated to the floating-deck shell around it (the deck got a gradient strip in
pass 2; the controls inside did not change shape).
*Direction:* regroup into ClipCraft tool clusters (pill groups like the player's
transport): Edit cluster, Mark/Record cluster, View cluster (snap state, zoom
slider as a designed unit), time readout as a tabular chip.

### 23. Stickers panel — `LeftPanel.jsx` `StickersTab`/`AnimatedStickers`
Bare emoji grid (25px glyphs on transparent buttons) + a native `<select>` for
categories + the legacy rail. The least designed panel in the app.
*Direction:* category chips + designed sticker tiles (surface tiles with hover
lift like Home cards); animated set gets preview tiles with the same chrome as assets.

### 24. Generic field-stack editors in the inspector — `Inspector.jsx`
The sticker/overlay simple editors and the gap editor still use the raw legacy stack
(`.fields` > `.field` label-over-input rows, native selects for Animation, plain info
box). Next to the redesigned ProjectDetails in the same panel, the drop-off is visible.
*Direction:* fold these into the #18/#20 inspector language (cards + micro-labels +
segmented controls); no native `<select>` for creative choices.

## RESTYLE-TOKENS (structure fine, tokens diverge — see DESIGN-SYSTEM.md)

### 25. Left-panel headers — `LeftPanel.jsx` `Head` (`.lib-head`) vs `.panel-head`
Two header languages coexist: library tabs use 15px/700 sentence-case `h2` + hint;
player/inspector decks use the glassy strip + 11px uppercase micro-label. Pick the
deck pattern (micro-label) for panel identity, keep `h2` only for content titles.
### 26. Effects tab — `LeftPanel.jsx` `EffectsTab`
Tile system is fine and previews are the real engine on real photos; chrome (group
labels, `.hint` paragraphs, mode explainer block) is plain. Restyle group headers +
hint treatment to tokens; merge the dual explainer paragraphs into one designed note.
### 27. Transitions tab — `LeftPanel.jsx` `TransitionsTab`
Content is strong (real previews, packs, favourites); divergence is chrome: duration
slider is a raw `.field` range, view switch is `.seg-tabs`, chips row wraps loosely.
Restyle to the segmented + chip spec; the white-search bug is in-flight (#13).
### 28. Filters + LUT browser — `LeftPanel.jsx` `FiltersTab`/`LutBrowser`, `FilterThumbs.jsx`
Tiles now use real photos (recent fix), but a drawn-gradient placeholder
(`.filter-thumb i`, amber→violet→green) still ships as the loading/fallback art and
category titles (`.look-cat-title`) are plain text rows. Restyle titles; replace the
gradient placeholder with a brand-surface skeleton.
### 29. Adjust / grading — `GradePanel.jsx`, `HslCurves.jsx`, `Scopes.jsx`
Custom `.grade-range` sliders are a second slider dialect (colored tracks) next to
the global violet-thumb slider. Keep the colored-track idea (it is Resolve-like and
useful) but tokenize: same thumb, track heights, value chips (`.grade-num`) in the
shared numeric style. Scopes canvas frame + seg control restyle to tokens.
### 30. Captions panel — `LeftPanel.jsx` `CaptionsTab`
Stacked generic `.card`s (generate / style / SRT import / add-line) with native
selects for language/model. Restyle cards to the deck language and selects to the
shared select spec; the progress block and error box already follow tokens.
### 31. Lane headers — `Timeline.jsx` `.tl-head[data-lane]`
Already have lane-accent inset bar + tinted icon chip (good). Divergence: lane accent
for `video` resolves to `--clip-video` #2b5ccf (blue) while clip bodies and the rest
of the identity are violet-led; header height/type scale differs from panel
micro-labels. Tokenize: one lane-color table shared by heads, clips, and + buttons.
### 32. Timeline clips + playhead line — `Timeline.jsx`
Clip bodies (filmstrip/waveform) are functional and modern; radii (clip radius vs
deck 18px), selection outline, and transition-junction spacing predate the deck
language (junction itself in-flight #11). Restyle radii/selection to tokens.
### 33. Context menus — `ContextMenu.jsx`
Clean and complete (icons, kbd hints, separators, disabled hints). Diverges only in
tokens: surface-3 bg, 9px radius, shadow 0 12px 32px/.5 vs the menu spec (12px
radius, deck shadow). Restyle to the shared menu spec shared with transport menus.
### 34. Screen-record dialogs — `ScreenRecordDialog.jsx`
Countdown numeral, live pill, converting state — all inside the generic `.modal`
(#21). Restyle with the family; the 64px countdown type is off-scale (codify or fold
to the display step).
### 35. Text-to-speech panel — `TextToSpeech.jsx` (inside Audio tab)
Form stack + voice list in legacy field language. Restyle to the audio-surface
language of #16 (it lives inside that tab).
### 36. Font picker — `FontPicker.jsx`
Popover list of font names; plain rows. Restyle rows to menu spec, render each name
in its own font at the type scale (previews exist via TextPreview in some paths).
### 37. Template slot strip — `SlotStrip.jsx`
Post-template strip above the timeline: functional, plain bar. Restyle to a deck
strip with numbered slot chips matching the templates gallery (#14).
### 38. Media favorites — `MediaFavorites.jsx`
Reuses rows/cards from elsewhere; empty state is a plain note. Restyle empty state
+ row chrome to the asset language.
### 39. Media peek — `MediaPeek.jsx`
Reuses `.stage`/`.transport` (good) but its scrubber is a raw range input and the
name/actions cluster is unstyled relative to the player. Restyle scrubber to the
slider spec; align the peek pill with the player's.
### 40. First-run stats note + update notice — `UsageStats.jsx`, `About.jsx` (`UpdateNotice`)
`.stats-note` floating card is serviceable; restyle to the notice spec (deck card,
brand icon chip) and remove `clipcraft.site` references from its copy (see #44).
### 41. Empty states (app-wide) — `.empty-note`, `.hint`
Outside Home, every empty state is a one-line muted paragraph ("No sticker matches.",
"Nothing found for…"). No shared empty-state component exists. Restyle: one
empty-state pattern (icon chip + title + one-line guidance + optional action),
reusing Home's mini-stage idea at panel scale.
### 42. Loading + error states (app-wide) — `.lib-loading`, `.lib-error`, `.error-box`, `.stock-ph`
Two error dialects (`.lib-error` inline row vs `.error-box` card) and three loading
dialects (spinner line, spinner tile, skeleton-less grids). Restyle to one loading
row + one error card spec; skeleton tiles for grids.

## DEAD / legacy remnants

### 48. `Generate.jsx` — DEAD
482 lines, no importers (its dock tab was removed at Hamza's order). It still exists
in the tree with its own `.gen-*` CSS. Decide deliberately: delete file + CSS, or it
will keep confusing future passes.
### 49. Legacy brand strings — content traces
`clipcraft.site` (the original project's domain) still appears in user-facing copy:
App.jsx template-upload instruction ("upload the folder at clipcraft.site/admin/
templates"), UsageStats privacy copy + `PRIVACY_URL`, Templates.jsx header comment
and its remote feed. Not visual layout, but they are original-app traces; the
templates item is in-flight (#14), the stats copy is not assigned to anyone yet.
### 50. Dual CSS eras in `styles.css`
The file is two design eras concatenated: the original flat system (lines 1–~1650)
and the pass-2 deck overrides (lines ~1650–1983) that re-skin the same classes, plus
appended feature blocks (about2, settings2, pilot2, transport menus…). Several
tokens are defined twice with different values (scrollbars: 10px/surface-4 vs
9px/#2e2e44 + violet hover; sliders: `accent-color` vs full custom webkit). Any
redesign phase should consolidate to one definition per component — see
DESIGN-SYSTEM "Divergences" — or the overrides will keep fighting.
