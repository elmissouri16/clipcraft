# Design references (Hamza, 2026-10-30) — inspiration only

Downloaded copies of the five references Hamza pointed at. They informed usability and
layout language only; no branding, colours, icons or exact arrangement were copied.
ClipCraft keeps its own layout, components and the violet logo theme.

| File | Source | What was taken from it |
|---|---|---|
| ref1-filmora-start-screen.png | Filmora start screen (Wondershare guide) | Start-screen clarity: an aspect-ratio choice presented up front as part of starting a project, a prominent New Project entry, Open Project within reach, recent projects as a thumbnail grid below. ClipCraft's preset stage + recents shelf already follow this; a chooser label was added above the preset cards. |
| ref2-capcut-desktop-editor.jpg | CapCut start screen (tutsplus article) | Home hierarchy: one big "new project" entry first, then a projects shelf with a count and search. Added: recents count in the heading and a working recents search. |
| ref3-vn-pc-editor.webp | VN (VlogNow) PC editor banner | Friendly editor density: category tabs over the library, colour-separated timeline tracks (each track type reads at a glance), labelled tool ribbon under the timeline. Confirmed the polish pass direction (lane-head chips, coloured playhead); no layout change needed. |
| ref4-editor-thumb.jpg | Filmora editor (French UI) | Editor structure check: tabbed left library, player centre, tabbed right inspector, Export top-right, named track heads (Video 1 / Audio 1). ClipCraft's workspace already matches this structure with its own components. |
| ref5-editor-thumb.jpg | CapCut desktop editor | Editor structure check: media grid + waveforms left, player centre, contextual inspector right, filmstrip + waveform timeline. Same conclusion as ref4. |
